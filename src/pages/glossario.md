## Glossário

| Termo | O que é |
|:--|:--|
| Coração | o dado que você rola |
| Marca | a dificuldade fixa (proposta) |
| Margem | a diferença entre o Coração e a dificuldade |
| Degrau | subir ou descer o tamanho do dado |
| Roda | quem domina quem entre os pecados |
| Vício | o seu pecado d12 |
| Jejum | o seu pecado d4 |
| Contenção | resistir à tentação rolando abaixo |
| Guarda | o pecado com que você se defende, à vista |
| Recurso | o que a sua classe ganha e gasta no turno |
| Fôlego | o amortecedor; volta no fim da cena |
| Ferida | dano de verdade: Leve, Grave, Mortal |
| Lesão | Ferida que vira Cicatriz |
| À Beira | caído, perto da morte |
| Pesagem | a cena da morte, com três árbitros |
| Zona | uma área nomeada do campo de batalha |
| Etiqueta | o pecado de uma zona, magia ou obstáculo |
| Fios | o recurso do Mago e o nível da magia |
| Rasgo | quando a magia sai do controle |
| Dívida | o que você deve a um Credor |
| Credor | a Bruxa ou entidade a quem você deve |
| Culto | subclasse de uma Bruxa que não exige pacto |
| Voto | a promessa de um pacto, com 3 caixas de Tentação |
| Peso | o nível do personagem |
| Prova | o feito que libera os Pesos seguintes |
| Vocação | a multiclasse |
| Cinto | as no máximo 5 opções ativas em combate |

<div class="rev">

Este glossário é o maior risco do sistema. Cada termo novo é uma coisa que o jogador precisa lembrar. Antes de criar qualquer regra nova, a pergunta é: dá para fazer isso com um termo que já existe?

</div>
